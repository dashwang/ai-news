# 用户反馈 - 公众号写作风格问题

## 问题1: AI感太重 (2026-03-24)
- **问题**: 内容写得太AI感
- **具体表现**: 
  - 每个色块都是橙色、绿色、蓝色，太千篇一律
  - 语气太"AI"，不够像真人
- **用户原话**: "不行啊不行啊，你这内容写得太ai感了"

## 改进方向
1. **配色**: 不要每次都用橙色、绿色、蓝色分块，学人类的配色
2. **开头**: 去掉橙色头部，直接用问题或故事开场
3. **金句**: 更多口语化、真正能传播的金句
4. **整体**: 不要堆砌AI术语，像真人公众号那样写

## 下次改进
- 写之前先想：如果是我朋友在看，怎么写？
- 配色参考：多看看人类写的10w+公众号
- 金句标准：能不能单独截出来发朋友圈？
