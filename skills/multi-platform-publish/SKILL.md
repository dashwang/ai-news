# 多平台分发 Skill

## 概述

单内容多平台发布自动化工具。同一篇文章，自动改编成不同平台的版本并发布。

## 支持平台

| 平台 | 内容类型 | 字数 | 风格 |
|------|----------|------|------|
| 微信公众号 | 深度长文 | 3000+ | 详细全面 |
| 知乎 | 专业深度 | 2000+ | 问题导向 |
| 今日头条 | 资讯爆款 | 1000-1500 | 观点鲜明 |
| 雪球 | 财经分析 | 800-1200 | 投资逻辑 |
| 微博 | 短资讯 | 300-500 | 话题引导 |

## 内容改编策略

### 标题改编

```
公众号: "两天做出AI产品，收获几千用户疯狂增长"
知乎:   "一个前字节工程师如何用AI两天做出产品？"
头条:   "太疯狂！用AI两天做出产品，用户破千！"
雪球:   "AI时代：一个人=一个团队"
微博:   #AI创业# 两天做出产品，用户几千...
```

### 正文改编

```
公众号: 完整版，3000+字，多角度深入
知乎:  聚焦1-2个核心观点，2000字
头条:  突出冲突和悬念，1500字
雪球:  数据和投资视角，1000字
微博:  核心金句+引导，300字
```

## 使用方法

### 1. 创建内容

```bash
# 基于原始素材生成多平台版本
```

### 2. 平台适配

每个平台有不同的格式要求：
- 知乎：支持 Markdown，部分平台不支持
- 头条：标题党风格，但要有内涵
- 雪球：数据和投资逻辑优先

### 3. 发布

各平台发布方式：

| 平台 | API | 状态 |
|------|-----|------|
| 公众号 | Railway | ✅ |
| 知乎 | 需要申请 | ⏳ |
| 头条 | 需要申请 | ⏳ |
| 雪球 | 需要申请 | ⏳ |

## 工作流程

```
原始素材 (播客/新闻/文章)
        ↓
内容分析 (提取核心观点、金句)
        ↓
平台改编 (生成5个版本)
        ↓
平台发布 (公众号/知乎/头条/雪球/微博)
        ↓
数据追踪 (阅读量/转化)
```
