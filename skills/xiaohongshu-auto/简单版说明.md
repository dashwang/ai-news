# 小红书自动登录工具

## 步骤

### 1. 安装 Node.js
去这里下载并安装：https://nodejs.org （选 LTS 版本）

### 2. 创建文件夹
在桌面创建一个文件夹叫 `xiaohongshu`

### 3. 创建两个文件

**文件1: package.json** (新建一个文件，复制下面内容粘贴进去)
```json
{
  "name": "xiaohongshu-login",
  "version": "1.0.0",
  "main": "login.js",
  "dependencies": {
    "playwright": "^1.40.0"
  }
}
```

**文件2: login.js** (新建一个文件，复制下面内容粘贴进去)
```javascript
const { chromium } = require('playwright');
const fs = require('fs');

async function main() {
  console.log('🚀 启动浏览器...');
  const browser = await chromium.launch({ headless: false, slowMo: 100 });
  const context = await browser.newContext();
  const page = await context.newPage();
  
  console.log('📱 请扫码登录小红书...');
  await page.goto('https://www.xiaohongshu.com/explore');
  
  try {
    await page.waitForURL('**/creator.xiaohongshu.com/**', { timeout: 300000 });
    console.log('✅ 登录成功！');
  } catch (e) {
    console.log('❌ 登录超时');
    await browser.close();
    process.exit(1);
  }
  
  const cookies = await context.cookies();
  fs.writeFileSync('xiaohongshu_cookies.json', JSON.stringify(cookies, null, 2));
  console.log('✅ Cookies 已保存！');
  console.log('📧 请把这个文件发给小龙虾 🦞');
  await page.waitForTimeout(2000);
  await browser.close();
}

main();
```

### 4. 安装依赖
打开终端（Terminal 或 CMD），进入文件夹：
```bash
cd 桌面/xiaohongshu
npm install
```

### 5. 运行
```bash
node login.js
```

### 6. 扫码登录
- 浏览器会弹出
- 用小红书app扫码登录
- 登录成功后会自动保存文件
